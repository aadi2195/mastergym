## 🚀 How to Host on GitHub Pages (Step-by-Step)

### Option A: Using GitHub Desktop / Git CLI

1. **Initialize Git & Commit**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Glorious Gym Master Website"
   ```

2. **Create a new repository on GitHub** (e.g., `glorious-gym` or `<your-username>.github.io`).

3. **Push your code to GitHub**:
   ```bash
   git branch -M main
   git remote add origin https://github.com/<YOUR_USERNAME>/<REPO_NAME>.git
   git push -u origin main
   ```

4. **Enable GitHub Pages**:
   - Go to your repository on GitHub.
   - Click on **Settings** (⚙️) -> **Pages** (in the left sidebar).
   - Under **Build and deployment** > **Source**, select **Deploy from a branch**.
   - Under **Branch**, select `main` and folder `/ (root)`, then click **Save**.
   - Your website will be live in ~60 seconds at `https://<YOUR_USERNAME>.github.io/<REPO_NAME>/`!
